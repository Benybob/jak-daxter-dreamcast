# Building the Dreamcast workbench

2026-10-21. (AI-assisted). Windows is the fully exercised development setup.
Use Git, Python 3.12 with Pillow, MSYS2 MinGW64 GCC/CMake/Ninja, zlib development
headers/static library and 7-Zip.
The SDK setup downloads substantial compiler/KOS archives into the workspace.

Keep the repository under a workspace containing sibling tool directories:

```text
dc-work/
  jak-project/       # clone of this fork
  dc-sdk/           # generated by SDK setup
  kos-source/       # generated by SDK setup
  og-host/          # generated original GOAL frontend
  flycast/          # supply flycast.exe here for native verification
```

```powershell
git clone https://github.com/Benybob/jak-daxter-dreamcast.git dc-work/jak-project
cd dc-work/jak-project
python -m pip install Pillow
./ports/dreamcast/build_host_windows.ps1
python ports/dreamcast/setup_windows_sdk.py
python ports/dreamcast/build_goal_frontend_windows.py
```

The host wrapper prepends the compiler directory to PATH so cc1 can locate
MinGW DLLs. Override its -Compiler and -Python parameters if needed. The default
MSYS2 location is C:/msys64. The frontend build needs working Windows short paths
when directories contain spaces. Scripts accept workspace/tool overrides; use
--help for details. Do not install SDK components globally through these scripts.

Install Flycast separately at the path above, then run the native checks:

```powershell
python ports/dreamcast/build_runtime_goal.py --verify
python ports/dreamcast/build_numeric_goal.py --verify
python ports/dreamcast/build_objects.py --verify
```

Run SH-4 build scripts sequentially; they share generated build configuration.
The object suite without retail archives has 98 checks; the 182-check local
result included two original assets from the owner's ISO. Compiler/runtime and
numeric probes use source/synthetic fixtures and need no ISO. Some host tests
skip independent assembler/GCC oracles until the SH-4 SDK is installed; rerun
the host wrapper after both SDK and frontend setup to cover those tests,
including the original-frontend named-local integration tests.

To reproduce the two small known compiler gaps:

```powershell
python ports/dreamcast/repros/reproduce.py
```

The original-source scanner/converters accept your own extracted assets. See
OBJECTS.md and TEXTURES.md; keep all resulting game bytes outside Git. The
textured viewer needs a locally converted scene, or a synthetic development
fixture. No real-scene ELF is included in this repository.

Compressed block tests require host zlib headers/library; native compression tests
require KOS ports zlib in the configured SDK prefix. Install that dependency using
the standard KOS ports workflow before building jak-dc-inflate.elf. SDK bootstrap
does not install zlib automatically. See [SECTOR_INFLATE.md](SECTOR_INFLATE.md).

For host development on Linux, use Python/Pillow, a C99 compiler, Make and zlib
development headers/library:

```sh
make -C ports/dreamcast host
make -C ports/dreamcast test
```

The Linux SDK helper is setup_toolchain.sh. Its layout differs from the verified
Windows setup; Linux host/SDK integration beyond the documented helper needs
contributor validation. No CI success or broad platform support is claimed.

The experimental original-background sector writer and bounded native reader
are documented in [RENDER_SECTORS.md](RENDER_SECTORS.md). The default
`jak-dc-render-io.elf` fixture is synthetic; private full-background tests require
explicit local conversion. It is a CPU reader diagnostic, not a playable
streaming renderer. Preserve generated real-data packages and embedding ELFs
outside Git. KOS zlib is required for this target too. (AI-assisted)

The separate `jak-dc-render-gpu.elf` oracle validates resident color textures
and staged GPU ownership, with original-free default input. See
[RESIDENT_TEXTURES.md](RESIDENT_TEXTURES.md). Private ROM-disk objects refresh
on each target build so changing to an older asset directory cannot keep stale
embedded data. These are diagnostics, not a complete streaming game. (AI-assisted)
